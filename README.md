# hackathon-1026

Прототип автозаполнения характеристик товаров для ЛК поставщика М.Видео.

## Продуктовый бриф

**Продукт.** Помощник в шаге онбординга «Заведите карточки товаров»: селлер вводит название и описание — сервис извлекает обязательные атрибуты категории, приводит значения к канону каталога и показывает уверенность по каждому полю. Сомнительные поля селлер правит вручную.

**Пользователь.** Селлер / менеджер по контенту у поставщика М.Видео: много SKU, мало времени, не обязан знать таксономию площадки. Описания часто копирует «как есть» с сайта производителя.

**Проблема.** Характеристики спрятаны в свободном тексте и пишутся по-разному («алый» / «красный» / «red»). Ручное заполнение долгое и ошибочное → товар не попадает в фильтры и поиск → ниже продажи у селлера и GMV у площадки.

**Ценность.** Селлер быстрее заводит полные карточки в формате М.Видео и видит, каким полям можно доверять. Площадка получает выше покрытие атрибутов, лучше поиск/фильтры и меньше мусора в каталоге. Решение не выдумывает характеристики: значение опирается на текст карточки; ниже порога уверенности (0,85) — ручная проверка.

**Как выглядит снаружи.** Три экрана: ввод названия и описания → ожидание («Изучаю информацию и готовлю карточку») → результат (атрибут / значение / уверенность) с правкой полей и переходом к новой карточке. Вход API: `title`, `description` (+ опционально сырые атрибуты продавца). Выход: список `{attribute, value, confidence}` по обязательным полям категории.

## Запуск прототипа

```bash
source .venv/bin/activate
pip install -r backend/requirements.txt
uvicorn main:app --app-dir backend --reload --port 8000
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000)

Сценарий: название + описание → ожидание → атрибуты с уверенностью → правка полей → новая карточка.
